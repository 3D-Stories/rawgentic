## The gate

**Does a pane ever actually report `blocked`?** Never once observed (right now: 6 idle, 1 working,
1 unknown).

- **Confirmed:** `blocked` is a valid herdr status — `herdr agent wait <pane> --until blocked
  --timeout 2000` accepts the value and returns `{"error":{"code":"timeout"}}`, and the enum is
  recorded at `docs/runbooks/herdr.md:286`.
- **Unverified:** that herdr's claude integration ever *sets* it on an approval prompt.
  `pane.agent_status_changed` produced 0 frames in 225 s of subscribed probing.
- **Inconclusive method, stated so it isn't re-run:** grepping `~/.config/herdr/herdr-server.log`
  for `blocked` returns 0 — but it also returns 0 for `working`, `idle` and `agent_status`, which
  are all live right now. The server never logs status. That grep proves nothing.

If herdr never sets `blocked`, **#612 is a correct implementation of an event that does not
happen**, and its 96 tests pass because they synthesise the frame themselves.

### Tier 7 — Context-pressure trigger #687 · void until #687 ships

Added 2026-07-28 at the owner's instruction. Every check here is void until #687 is merged: they test
a trigger that does not exist yet. The risk column says "restarts this session" because C7 is the
whole point of the feature and cannot be tested without actually handing a session over.

- **C1** The meter reads context from a session transcript and its number agrees with an independently
  computed one for the same session. Fails if it disagrees by more than cache-read drift.
- **C2** A threshold crossing emits the directive **once per tier**, not once per turn
  (record-before-emit). Fails if a second identical nag appears while the tier is unchanged.
- **C3** Cadence holds: at most one check per **5 turns or 5 minutes, whichever comes first**. Fails if
  a check runs on consecutive turns inside the window — and note the honest constraint that hooks fire
  on events, not timers, so the 5-minute arm is evaluated at the next event, not at the 5-minute mark.
- **C4** **A mid-phase break is refused.** With the step-state pointer showing a position mid-step, the
  trigger defers; at a step boundary it fires. This is the check that distinguishes the feature from a
  blunt "you are at 80%, stop now".
- **C5** Thresholds are relative, not absolute: the SAME token count tiers differently against a 200k
  window and a 1M one. (#654 measured a real case — 173,667 tokens is 17.4% of 1M but 86.8% of 200k.)
- **C6** Fail-OPEN: an absent, truncated or corrupt transcript emits nothing and never blocks a turn.
- **C7** End to end, on a real session: over the hard threshold at a safe seam, a handoff is written,
  a successor pane is created, bound, prompted, given the goal and the task list, and the predecessor
  is retired LAST. Reuses the #665 ladder and #682's bind-first ordering — no second mechanism.
- **C8** *(human, one read)* Did the break land at a moment you would have chosen? The only genuinely
  subjective part; everything else above is mechanical.

## What is actually the owner's — re-triaged 2026-07-28

The original plan listed six checks as human-only. The owner asked for that set to be as small as
technically possible, and on inspection **most of them were not one indivisible check** — they were an
agent-checkable fact welded to an owner judgement. Split apart, **six move to me** (H7, R3, D3, plus
the agent halves W8a, V3a, L3a) and **four one-sentence judgements** remain — with tier 7's new C8
added, the run-2 totals are **41 checks: 37 agent, 4 owner**.

| R3 | "Only the owner knows what is running" | **MINE.** Authorised, and what is running is enumerable (`pgrep`, `herdr pane list`, the session registry). |

**So the owner's UAT is now four short judgements — W8b, V3b, L3b, C8 — and nothing that requires
setting anything up.** Each arrives with the evidence already gathered and a recommendation attached.

**What did NOT move, and why that matters:** none of these conversions weakens a check. A converted
check still has to produce its evidence and record a verdict through the harness, which refuses an
unknown id and refuses a verdict with no evidence. The judgement halves were split OUT rather than
absorbed, precisely so that "the agent decided it looked fine" can never stand in for the owner's
call.
