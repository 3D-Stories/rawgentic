## The gate

**Does a pane ever actually report `blocked`?** Never once observed (right now: 6 idle, 1 working,
1 unknown).

- **Confirmed:** `blocked` is a valid herdr status — `herdr agent wait <pane> --until blocked
  --timeout 2000` accepts the value and returns `{"error":{"code":"timeout"}}`, and the enum is
  recorded at `docs/runbooks/herdr.md:286`.
- **Unverified:** that herdr's claude integration ever *sets* it on an approval prompt.
  `pane.agent_status_changed` produced 0 frames in 225 s of subscribed probing.
- **Inconclusive method, stated so it isn't re-run:** grepping `~/.config/herdr/herdr-server.log`
  for `blocked` returns 0 — but it also returns 0 for `working`, `idle` and `agent_status`, which
  are all live right now. The server never logs status. That grep proves nothing.

If herdr never sets `blocked`, **#612 is a correct implementation of an event that does not
happen**, and its 96 tests pass because they synthesise the frame themselves.
